# 2027 호반그룹 신입사원 채용 키비주얼

Illustrator 원본의 배치와 질감을 유지하면서 각 요소를 독립 레이어로 분리하고 GSAP 모션을 적용한 반응형 웹 페이지입니다.

## 주요 모션

- 호랑이와 토끼의 고정 관절 팔·연필 드로잉 모션
- 원본 질감을 보존한 집 13획·금괴 45획 순차 마스크 드로잉
- 획별 픽셀 소유 마스크로 다음 획 사전 노출 방지
- 캐릭터의 두 번 통통 뛰는 마무리 동작
- 골프채 스윙과 골프공의 독립 바운스
- 폭죽, 나무, 풍력발전기, 장식 요소의 독립 반복 모션
- 모바일 전용 재배치

## 실행

```bash
npm install
npm run dev
```

## 정적 빌드

```bash
npm run build
```

빌드 결과는 `out/` 디렉터리에 생성됩니다.

## 드로잉 검증

```bash
npm run verify:drawing
```

획 진행과 펜 리프트를 포함한 전체 드로잉 시간축을 60/100/120Hz로 검사하며, 다음 획 사전 노출·역행·과도한 정지·완성 원본 차이를 함께 검증합니다.
